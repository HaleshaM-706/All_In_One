# Image to PDF Converter

A production-ready React 19 + Vite image-to-PDF converter with a modular architecture for ads, premium features, analytics, and future monetization.

## Features

- Upload multiple PNG/JPG/JPEG images
- Drag-and-drop upload
- Reorder, rotate, remove, and clear images
- Generate a PDF entirely in the browser
- Feature-flag driven ads and premium UI
- Analytics event hooks
- Responsive layout with accessibility support

## Environment Configuration

Copy .env.example to .env and adjust values.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
